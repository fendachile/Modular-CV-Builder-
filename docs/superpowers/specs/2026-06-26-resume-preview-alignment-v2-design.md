# 简历预览对齐修正设计说明 v2

## 1. 目标

修正简历预览区中项目经历、工作经历、教育经历的头部对齐方式，使其更贴近用户提供的参考标注图。

本次只调整预览区的视觉布局，不修改左侧表单数据结构，不新增字段。

## 2. 本次修正范围

### 2.1 项目经历

当前问题：

- 项目中间职责或角色文本位置偏右
- 与左侧标题列没有形成稳定的视觉对齐关系

修正要求：

- 项目经历的中间职责文本不再做居中对齐
- 改为与左侧项目名称列形成统一的纵向参考线
- 视觉效果上，中间职责整体左移，贴近名称列的中轴参考位置
- 右侧仍然只显示时间，并保持右对齐

### 2.2 工作经历

当前问题：

- 地点与时间仍在同一行或同一水平层级中

修正要求：

- 右侧信息区改为上下两行堆叠
- 时间在上
- 地点在下
- 两行都采用右对齐

### 2.3 教育经历

当前问题：

- 学历与时间仍在同一行或同一水平层级中

修正要求：

- 右侧信息区改为上下两行堆叠
- 时间在上
- 学历在下
- 两行都采用右对齐

## 3. 布局规则

### 3.1 项目经历头部

采用三段式布局：

1. 左侧：项目名称
2. 中间：项目职责或项目角色
3. 右侧：项目时间

规则如下：

- 左侧项目名称保持主标题样式
- 中间职责文本不居中到整列中央，而是向左靠齐到参考线位置
- 右侧时间固定右对齐

### 3.2 工作经历头部

采用三段式布局：

1. 左侧：公司名称
2. 中间：岗位名称
3. 右侧：两行信息区

右侧两行顺序：

1. 任职时间
2. 工作地点

规则如下：

- 中间岗位名称保留中部信息位
- 右侧整体右对齐
- 时间与地点之间保持较小的垂直间距

### 3.3 教育经历头部

采用三段式布局：

1. 左侧：学校名称
2. 中间：专业
3. 右侧：两行信息区

右侧两行顺序：

1. 在校时间
2. 学历

规则如下：

- 中间专业保留中部信息位
- 右侧整体右对齐
- 时间在视觉上优先于学历

## 4. 实现边界

- 不调整表单字段名称
- 不调整模块顺序
- 不修改 PDF 导出逻辑
- 不新增拖拽或编辑能力
- 仅修改预览结构和样式

## 5. 验收标准

- 项目经历中间职责位置明显左移，并与左侧名称列形成更稳定的纵向对齐关系
- 工作经历中，时间位于地点上方，二者都右对齐
- 教育经历中，时间位于学历上方，二者都右对齐
- 其他模块排版不受影响
- 自动化测试和生产构建通过
