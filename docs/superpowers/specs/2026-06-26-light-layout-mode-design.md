# 轻量排版模式设计文档

## 1. 目标

在当前简历编辑网页中增加一套轻量排版模式，用于在右侧预览区直接拖动部分文本块进行精细对齐。

本次能力目标如下：

- 预览区直接拖动指定文本块
- 支持拖拽吸附
- 支持参考线辅助
- 支持显示或隐藏网格线
- 拖动结果保存到浏览器本地
- 导出 PDF 时保留最终排版位置，但不显示网格线和辅助层

## 2. 第一版范围

### 包含

- 排版模式开关
- 网格线显示或隐藏开关
- 重置排版按钮
- 预览区内文本块拖动
- 网格吸附
- 中轴线与局部参考线辅助
- 浏览器本地保存排版结果
- 导出 PDF 时隐藏网格与辅助层

### 不包含

- 任意元素自由拖动
- 时间、地点、学历等字段自由拖动
- 缩放、旋转
- 多选拖动
- 键盘微调
- 跨模块拖动
- 云端同步

## 3. 可拖动对象范围

第一版仅允许以下三类中间字段拖动：

1. 项目经历中的项目职责或项目角色
2. 工作经历中的岗位名称
3. 教育经历中的专业名称

规则如下：

- 每一条经历单独可拖动
- 每条记录拥有独立位置
- 拖动位置互不影响
- 左侧表单结构不变
- 文本内容仍由左侧表单控制

## 4. 交互设计

### 4.1 模式切换

右侧预览区增加排版工具栏，提供以下开关：

- 排版模式开关
- 网格线显示或隐藏开关
- 重置排版按钮

规则如下：

- 默认处于普通预览模式
- 仅在开启排版模式后，可拖动文本块显示拖动交互
- 关闭排版模式后，仍展示拖动后的最终结果，但不显示编辑辅助信息

### 4.2 拖动反馈

当进入排版模式后：

- 可拖动文本块显示悬停提示
- 拖动中的文本块显示边框高亮
- 预览纸张显示辅助参考线
- 如开启网格线，则显示浅色网格层

### 4.3 网格线

网格线仅作为辅助排版层。

规则如下：

- 仅在预览区显示
- 仅在用户开启网格线时显示
- 不参与 PDF 导出
- 不改变正文实际内容

### 4.4 重置排版

点击重置排版后：

- 清空全部拖动偏移
- 恢复所有可拖动文本块到默认锚点
- 保留简历正文内容不变

## 5. 数据结构设计

本次不修改原有简历数据模型，新增独立排版状态。

### 5.1 简历正文数据

仍然使用现有 `resumeData` 保存文本内容。

### 5.2 排版数据

新增 `layoutState` 用于保存可拖动文本块的位置与显示状态。

建议结构如下：

```ts
type LayoutBlockId = string;

type LayoutBlockState = {
  x: number;
  y: number;
  visible: boolean;
};

type LayoutState = {
  blocks: Record<LayoutBlockId, LayoutBlockState>;
  showGrid: boolean;
  layoutMode: boolean;
};
```

### 5.3 可拖动块 ID 规则

每条经历拥有唯一拖动块 ID：

- `project-role-project-1`
- `work-title-work-1`
- `education-major-education-1`

规则如下：

- 项目经历使用项目条目 id
- 工作经历使用工作条目 id
- 教育经历使用教育条目 id
- 确保每条记录独立保存位置

## 6. 本地保存策略

使用浏览器本地存储保存排版状态。

规则如下：

- 页面初始化时读取本地存储
- 拖动结束后写回本地存储
- 刷新页面后恢复上次拖动结果
- 新增经历时自动生成默认布局位置
- 删除经历时清理对应布局记录

本地保存内容包括：

- 每个拖动块的坐标
- 当前是否显示网格线

不要求保存内容编辑历史。

## 7. 默认锚点设计

每个可拖动块都应有默认锚点。

拖动并不是彻底脱离原布局，而是在默认锚点基础上记录偏移量。

这样做的原因：

- 便于恢复默认
- 便于未来模板升级
- 保证没有布局数据时仍有稳定初始位置

默认锚点如下：

- 项目角色位于项目头部中间区域
- 岗位名称位于工作头部中间区域
- 专业名称位于教育头部中间区域

## 8. 吸附与参考线设计

### 8.1 网格吸附

采用轻量吸附，不做复杂设计软件级别约束。

建议规则：

- 基础网格尺寸使用 `8px`
- 拖动结束时优先吸附到最近网格点
- 吸附阈值控制在 `6px` 到 `10px`

### 8.2 参考线

第一版提供两类参考线：

1. 页面中轴参考线
2. 当前经历头部的局部参考线

说明：

- 页面中轴参考线用于帮助控制中部文本整体纵向关系
- 局部参考线用于帮助对齐当前经历的左列和右列

### 8.3 拖动边界

拖动对象必须限制在当前简历纸张内部。

规则如下：

- 不允许拖出版心区域
- 不允许拖到相邻模块外的极端位置
- 第一版只做纸张边界约束，不做复杂碰撞检测

## 9. 组件设计

建议在现有结构基础上新增以下组件或逻辑单元：

- `LayoutToolbar`
- `PreviewCanvas`
- `DraggableLabel`
- `GuideOverlay`

### 9.1 LayoutToolbar

职责：

- 排版模式开关
- 网格线开关
- 重置排版

### 9.2 PreviewCanvas

职责：

- 包裹整张简历纸张
- 提供拖动边界
- 承载网格层
- 承载参考线层

### 9.3 DraggableLabel

职责：

- 包裹可拖动文本
- 管理单个文本块拖动逻辑
- 处理吸附
- 通知位置保存

### 9.4 GuideOverlay

职责：

- 拖动时显示辅助参考线
- 非拖动时隐藏

## 10. 接入方式

现有 `ResumePreview` 保持主体结构不变。

仅在以下位置用可拖动文本块替换普通文本：

- 项目经历中的 `projectRole`
- 工作经历中的 `jobTitle`
- 教育经历中的 `major`

规则如下：

- 文本内容仍来自 `resumeData`
- 布局位置来自 `layoutState`
- 若没有保存数据，则回退到默认锚点

## 11. 数据流

数据流分为两条：

### 11.1 内容数据流

- 左侧表单修改 `resumeData`
- 右侧预览读取 `resumeData`

### 11.2 排版数据流

- 右侧排版模式修改 `layoutState`
- `layoutState` 保存到本地存储
- 右侧预览根据 `layoutState` 调整可拖动文本块位置

两类数据互相独立，避免内容编辑和排版编辑相互覆盖。

## 12. PDF 导出规则

导出 PDF 时应保留最终排版结果，但隐藏辅助信息。

导出时需要隐藏：

- 排版模式工具条
- 网格线
- 参考线
- 拖动边框
- 任何悬停提示

导出时需要保留：

- 拖动后的文本位置
- 简历正文内容

## 13. 测试重点

需要覆盖以下场景：

- 打开排版模式后目标文本块可拖动
- 拖动后位置发生变化
- 吸附后位置落到网格点或参考线附近
- 刷新页面后位置仍然保留
- 网格线开关可控制显示或隐藏
- 导出 PDF 时不显示辅助层
- 新增经历时自动生成默认位置
- 删除经历时清理对应布局数据

## 14. 实现顺序建议

推荐按以下顺序落地：

1. 增加排版模式开关、网格线开关、重置排版按钮
2. 增加 `layoutState` 与本地存储
3. 为三类文本块接入拖动能力
4. 增加网格吸附
5. 增加参考线
6. 处理导出时隐藏辅助层

## 15. 验收标准

当满足以下条件时视为完成：

- 预览区可以直接拖动三类指定文本块
- 每条经历的文本块可独立拖动
- 拖动后位置能保存在浏览器本地
- 页面提供网格线显示或隐藏开关
- 网格线不参与 PDF 导出
- 拖动具备轻量吸附与参考线辅助
- 刷新页面后布局结果可恢复
- 测试和构建通过
