# 简历排版编辑器 V2 设计文档

## 1. 目标

在现有简历模块化编辑工具基础上，升级为一套更接近轻量排版工具的网页成品。

本次升级目标如下：

- 修正项目角色、岗位名称、专业名称的中轴对齐问题
- 所有一级模块标题支持用户自定义编辑
- 右侧预览中的一级模块支持整体拖动
- 拖动时支持轻量吸附与参考线
- 预览区外圈增加标尺，辅助观察对齐
- PDF 导出保留最终拖动后的排版结果

## 2. 范围

### 包含

- 所有一级模块标题可编辑
- 一级模块整体拖动
- 字段级拖动继续保留
- 页面中轴吸附
- 网格吸附
- 模块间边缘吸附
- 顶部横向标尺
- 左侧纵向标尺
- 本地保存模块与字段布局
- 导出 PDF 时保留最终排版位置

### 不包含

- 任意字段自由拖动
- 模块旋转
- 模块缩放
- 多页简历编辑
- 云端保存
- 协同编辑

## 3. 关键交互

### 3.1 一级模块标题可编辑

所有一级模块都拥有可编辑标题：

- 基本信息
- 核心优势
- 项目经历
- 工作经历
- 教育经历
- 相关技能
- 其他信息

规则如下：

- 左侧编辑区为每个一级模块提供标题输入框
- 右侧预览实时使用用户修改后的标题
- 标题清空时自动回退默认标题
- 导出 PDF 使用当前标题文本

### 3.2 一级模块整体拖动

右侧预览中的每个一级模块作为一个整体拖动单元。

规则如下：

- 拖动模块时，标题和该模块全部正文一起移动
- 模块拖动结果保留到最终预览
- PDF 导出保留该最终位置
- 模块不可拖出纸张边界
- 当前仅正文一级模块可自由拖动
- 基本信息标题可编辑，但页眉本体暂不纳入模块自由拖动

### 3.3 字段级拖动继续保留

当前已支持的三类字段继续可拖动：

1. 项目经历中的项目角色
2. 工作经历中的岗位名称
3. 教育经历中的专业名称

规则如下：

- 每一条经历单独保存位置
- 字段拖动结果与模块拖动结果叠加生效
- 用户点击字段文字本体时优先拖动字段
- 用户点击模块其他区域时拖动整个模块

### 3.4 标尺与参考线

右侧预览外圈增加辅助标尺：

- 顶部横向标尺
- 左侧纵向标尺

拖动时显示：

- 当前拖动对象高亮边框
- 横向参考线
- 纵向参考线
- 标尺位置提示

标尺和参考线仅用于辅助排版，不参与 PDF 导出。

## 4. 对齐修正要求

需要先修正目前的对齐问题。

### 4.1 中间字段对齐

以下三类中间字段需统一按版心参考线对齐，不再出现漂移：

- 项目角色
- 岗位名称
- 专业名称

要求如下：

- 视觉上沿同一条中轴线排列
- 默认位置在未拖动时即合理
- 启用排版模式后仍允许继续微调

### 4.2 右侧堆叠信息

工作经历和教育经历右侧信息保持如下结构：

- 时间在上
- 地点或学历在下
- 整体右对齐

## 5. 数据结构

本次改造使用四类状态：

### 5.1 简历正文数据

继续使用 `resumeData` 保存正文内容。

### 5.2 一级标题数据

新增 `sectionTitles` 保存一级模块标题。

建议结构：

```ts
type SectionTitleKey = SectionKey | "basicInfo";
type SectionTitles = Record<SectionTitleKey, string>;
```

### 5.3 字段布局数据

继续使用字段级布局状态保存：

- 项目角色
- 岗位名称
- 专业名称

建议结构：

```ts
type LayoutState = {
  layoutMode: boolean;
  showGrid: boolean;
  blocks: Record<string, { x: number; y: number }>;
};
```

### 5.4 模块布局数据

新增模块级布局状态保存一级模块整体位置。

建议结构：

```ts
type SectionLayout = Record<SectionKey, { x: number; y: number }>;
```

说明：

- `basicInfo` 不进入模块自由拖动布局
- 一级模块整体位置单独存储，避免和字段级拖动混在一起

## 6. 拖动与吸附规则

### 6.1 拖动目标优先级

拖动优先级如下：

1. 点击字段级可拖动文本时，拖动字段
2. 点击模块正文区域时，拖动模块
3. 一次只允许一个拖动目标激活

### 6.2 吸附优先级

拖动吸附优先级如下：

1. 纸张边界限制
2. 页面中轴吸附
3. 模块边缘吸附
4. 网格吸附
5. 自由落点

### 6.3 边界与导出

规则如下：

- 模块和字段都不能拖出纸张边界
- 模块可互相靠近，但第一版不做复杂碰撞避让
- 导出 PDF 时保留最终位置，但隐藏辅助层

## 7. 组件设计

建议在现有结构上增量改造：

- `App`
- `SectionCard`
- `ResumePreview`
- `DraggableLabel`
- `DraggableSection`
- `RulerOverlay`
- `GuideOverlay`

### 7.1 App

职责：

- 管理正文数据
- 管理一级标题数据
- 管理字段布局
- 管理模块布局
- 管理 UI 状态

### 7.2 SectionCard

职责：

- 展示左侧模块卡片
- 提供模块标题编辑输入

### 7.3 ResumePreview

职责：

- 渲染右侧简历页面
- 承载模块拖动与字段拖动
- 承载网格、标尺与参考线

### 7.4 DraggableSection

职责：

- 包裹单个一级模块
- 处理模块整体拖动
- 计算吸附与边界

### 7.5 RulerOverlay

职责：

- 渲染顶部与左侧标尺
- 在拖动时反映当前位置

## 8. 本地保存策略

以下信息保存到浏览器本地：

- 一级标题文本
- 字段拖动位置
- 模块拖动位置
- 网格线显示开关

页面刷新后恢复上次编辑结果。

删除经历条目时：

- 清理对应字段拖动数据

模块布局数据按模块 key 保存，不随模块内条目变化丢失。

## 9. PDF 导出规则

导出 PDF 时：

### 保留

- 一级模块标题修改结果
- 字段拖动后的最终位置
- 模块拖动后的最终位置
- 正文内容

### 隐藏

- 网格线
- 参考线
- 标尺
- 拖动边框
- 排版模式工具栏

## 10. 测试重点

需要覆盖以下场景：

- 一级模块标题修改后左右同步更新
- 标题清空时回退默认值
- 三类中间字段默认对齐正确
- 模块整体可拖动
- 字段拖动与模块拖动互不冲突
- 标尺在排版模式下显示
- 网格与参考线开关正常
- 本地刷新后标题与布局恢复
- 导出模式隐藏辅助层
- 构建与测试通过

## 11. 验收标准

满足以下条件即视为完成：

- 预览中的一级模块支持整体拖动
- 所有一级模块标题可编辑
- 项目角色、岗位名称、专业名称默认对齐修正
- 拖动时存在吸附与参考线反馈
- 预览外侧存在顶部和左侧标尺
- 标题与布局结果本地保存
- PDF 导出保留最终排版位置
- 测试与构建通过
